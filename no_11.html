데이터 분석 알아보기
  • 데이터 분석은 데이터를 정리하고, 통계를 구하고, 그래프로 그려 보며 데이터의 특징을 찾는 과정이다.
  • 이 장에서는 외부 라이브러리 두 가지를 쓴다. pandas(판다스)는 표 형태의 데이터를 다루고, matplotlib(맷플롯립)은 그래프를 그린다.
  • 판다스는 행과 열로 이루어진 데이터프레임(DataFrame)으로 데이터를 다룬다. 4장의 2차원 리스트로 데이터프레임을 만들고, 10장처럼 CSV 파일로 저장하고 읽는다.
  • 이 장에서는 학생 6명의 국어, 영어, 수학 점수를 처음부터 끝까지 사용한다. 연습을 위해 만든 가상의 데이터이다.
11.1

라이브러리 준비하기

라이브러리 불러오기
import pandas as pd
import matplotlib.pyplot as plt
  • pandas와 matplotlib은 코랩에 이미 설치되어 있어서 import로 바로 불러온다.
  • pandas는 pd, matplotlib의 pyplot 모듈은 plt라는 별명으로 불러오는 것이 관례이다. 8장에서 배운 별명 붙이기(as)이다.
  • matplotlib.pyplot처럼 라이브러리 이름과 모듈 이름을 점으로 잇는다.
그래프에 한글 쓰기

코랩에는 한글 글꼴이 없어서 그래프의 제목이나 이름에 쓴 한글이 네모(□)로 깨진다. 노트북을 열면 처음에 아래 셀을 한 번 실행한다. 한글 글꼴을 설치하고 그래프의 글꼴로 정해 준다.

!pip install koreanize-matplotlib

줄 앞의 느낌표(!)는 파이썬 코드가 아니라 코랩 서버에 내리는 설치 명령이라는 표시이다. 한 번 실행하면 그 뒤의 셀에서는 다시 쓰지 않아도 된다. 코랩을 새로 열거나 세션을 다시 시작했다면 이 셀부터 다시 실행한다. 한글이 네모로 보이면 이 셀을 실행했는지 확인한다.

해설pandas를 pd로, matplotlib.pyplot을 plt로 불러왔다. __name__은 불러온 모듈의 원래 이름이다. 이 장의 실습은 모두 이 셀을 실행한 뒤에 실행한다.

기억하기

  • pandas는 표 형태의 데이터를, matplotlib은 그래프를 다루는 외부 라이브러리이다. 코랩에는 설치되어 있다.
  • import pandas as pd, import matplotlib.pyplot as plt처럼 별명을 붙여 불러온다.
  • 그래프에 한글을 쓰려면 노트북을 열 때 koreanize-matplotlib을 설치하고 불러오는 셀을 한 번 실행한다.

11.2데이터프레임 만들기

데이터프레임 알아보기
df = pd.DataFrame(2차원 리스트, columns=열 이름 리스트, index=행 이름 리스트)
df
  • 데이터프레임은 행과 열이 있는 표 모양의 2차원 데이터 구조이다.
  • pd.DataFrame(2차원 리스트)로 만든다. 2차원 리스트의 행 하나가 표의 한 행이 된다.

  • 코랩에서 셀의 마지막 줄에 df처럼 변수 이름만 쓰면 데이터프레임을 표 모양으로 보여 준다. print(df)는 글자로 출력한다.

11.3CSV로 저장하고 읽기

CSV 파일로 저장하고 읽기
df.to_csv('파일 이름.csv')
df = pd.read_csv('파일 이름.csv', index_col=0)
  • df.to_csv(파일 이름)은 데이터프레임을 CSV 파일로 저장한다. 행 이름도 첫 열에 함께 저장된다.
  • pd.read_csv(파일 이름)은 CSV 파일을 읽어 데이터프레임으로 만든다. 10장처럼 open()과 csv.reader를 쓰지 않아도 된다.
  • 첫 열이 행 이름이면 index_col=0을 넣어 0번 열을 행 이름으로 쓴다.

11.4열과 행 꺼내기

열과 행 꺼내기
df['열 이름']
df.loc['행 이름']
df.loc['행 이름', '열 이름']
  • df['열 이름']은 열 하나를 꺼낸다. 4장의 딕셔너리에서 키로 값을 꺼내는 것과 모양이 같다.
  • df.loc['행 이름']은 행 하나를 꺼낸다. loc는 위치(location)라는 뜻이다.
  • df.loc['행 이름', '열 이름']은 값 하나를 꺼낸다.
  • 꺼낸 열이나 행은 이름표가 붙은 1차원 데이터이다. 판다스에서는 이것을 시리즈(Series)라고 한다.

파이썬 실습 11-6열 하나 꺼내기

해설11.3에서 읽은 df를 이어서 쓴다. 국어 열을 꺼냈다. 왼쪽은 행 이름, 오른쪽은 값이다. 마지막 줄의 Name은 열 이름, dtype은 값의 자료형이다. int64는 정수라는 뜻이다.

파이썬 실습 11-7행 하나와 값 하나 꺼내기

① 행 하나 꺼내기

해설3번 학생의 행을 꺼냈다. 이번에는 왼쪽에 열 이름이 붙는다.

② 값 하나 꺼내기

print(df.loc['3번', '수학'])
print(df['영어']['5번'])

해설df.loc['3번', '수학']은 3번 행의 수학 값이다. df['영어']['5번']처럼 열을 먼저 꺼낸 뒤 행 이름을 써도 된다.

기억하기

  • df['열 이름']은 열 하나, df.loc['행 이름']은 행 하나를 꺼낸다.
  • df.loc['행 이름', '열 이름']으로 값 하나를 꺼낸다.
  • 없는 열 이름이나 행 이름을 쓰면 KeyError가 난다. 이름의 글자와 띄어쓰기를 정확히 쓴다.
