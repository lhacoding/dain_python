데이터 분석 알아보기
  • 데이터 분석은 데이터에서 질문의 답을 찾는 과정이다. 데이터를 정리하고, 통계를 구하고, 그래프로 그려 보며 특징과 관계를 살핀다. 이렇게 데이터를 여러모로 살펴보는 것을 탐색적 데이터 분석이라고 한다.
  • 이 장에서는 외부 라이브러리 두 가지를 쓴다. pandas(판다스)는 표 형태의 데이터를 다루고, matplotlib(맷플롯립)은 그래프를 그린다.
  • 판다스는 2차원 데이터 구조인 데이터프레임(DataFrame)으로 데이터를 다룬다. 10장의 CSV 파일을 바로 읽어 데이터프레임으로 만들 수 있다.
  • 이 장의 데이터는 연습을 위해 만든 가상의 데이터이다.

plt.plot(x값 리스트, y값 리스트)      # 꺾은선 그래프

  • plt.plot()은 꺾은선, plt.bar()는 막대, plt.pie()는 원, plt.scatter()는 점을 찍는 산점도 그래프를 그린다.
  • plt.title()은 그래프 제목, plt.xlabel()과 plt.ylabel()은 가로축과 세로축의 이름을 단다.
  • 그래프를 다 그렸으면 plt.show()로 화면에 보여 준다.

파이썬 실습 11-4원그래프로 비율 보기

9장의 용돈 관리처럼 한 달 용돈을 어디에 썼는지 정리했다.

import matplotlib.pyplot as plt

items = ['간식', '교통', '문구', '저축']
money = [30000, 20000, 10000, 40000]
plt.pie(money, labels=items, autopct='%.1f%%')
plt.title('한 달 용돈 사용')
plt.show()

해설plt.pie()는 값의 합을 100%로 놓고 각 값이 차지하는 비율만큼 원을 나눈다. labels에는 조각의 이름을 넣는다. autopct='%.1f%%'는 비율을 소수 첫째 자리까지 쓰고 뒤에 %를 붙이라는 뜻이다. %.1f가 소수 첫째 자리이고, %%는 % 기호 하나를 나타낸다. 1장 심화의 % 서식과 같은 규칙이다.

기억하기

  • 꺾은선은 plt.plot(), 막대는 plt.bar(), 원은 plt.pie(), 산점도는 plt.scatter()로 그린다.
  • 변화는 꺾은선, 비교는 막대, 비율은 원, 관계는 산점도로 나타낸다.
  • plt.title(), plt.xlabel(), plt.ylabel()로 제목과 축 이름을 달고, 마지막에 plt.show()를 쓴다.
  • 원그래프에 비율을 쓰려면 autopct='%.1f%%'를 넣는다.

데이터프레임 알아보기
import pandas as pd

df = pd.DataFrame({'열 이름1': [값, 값], '열 이름2': [값, 값]})
print(df)            # 전체 보기
print(df.head(3))    # 앞의 3행 보기(괄호를 비우면 5행)
print(df.shape)      # (행의 개수, 열의 개수)

  • 데이터프레임(DataFrame)은 판다스의 2차원 데이터 구조이다. 행과 열이 있는 표 모양이다.
  • 딕셔너리로 만들 때 키는 열 이름, 값은 그 열에 들어갈 리스트가 된다. 4장에서 배운 딕셔너리를 쓴다.
  • 행에는 0부터 시작하는 번호가 붙는데, 이것을 인덱스라고 한다.
  • df['열 이름']으로 열 하나를 꺼낸다. 꺼낸 열끼리 계산하면 같은 행의 값끼리 계산된다.

파이썬 실습 11-7열끼리 계산해 새 열 만들기

import pandas as pd

data = {'상품': ['우유', '빵', '김밥', '주스', '과자'],
        '가격': [1200, 1500, 2500, 1300, 1000],
        '판매량': [30, 25, 18, 22, 40]}
df = pd.DataFrame(data)
df['매출'] = df['가격'] * df['판매량']
print(df)
   상품    가격  판매량     매출
0  우유  1200   30  36000
1   빵  1500   25  37500
2  김밥  2500   18  45000
3  주스  1300   22  28600
4  과자  1000   40  40000

해설가격 열과 판매량 열을 곱하면 같은 행의 값끼리 곱해진다. 반복문 없이 다섯 행을 한 번에 계산한 것이다. 없는 열 이름에 대입하면 새 열이 오른쪽에 추가된다. 딕셔너리에 새 키를 대입해 항목을 추가한 것과 같은 방식이다.

기억하기

  • 데이터프레임은 행과 열로 된 판다스의 2차원 데이터 구조이다. 행 번호를 인덱스라고 한다.
  • pd.DataFrame(딕셔너리)로 만들면 키가 열 이름, 리스트가 열의 값이 된다.
  • head()로 앞부분, shape로 (행, 열)의 개수를 본다. df['열 이름']으로 열 하나를 꺼낸다.
  • df['새 열'] = 계산식으로 새 열을 만든다. 열끼리 계산하면 같은 행의 값끼리 계산된다.
