정렬과 탐색 알아보기
  • 심화이 장은 정렬과 탐색을 학교에서 깊이 다루는 학생을 위한 심화 장이다.
  • 알고리즘은 문제를 해결하는 방법이나 절차이다. 같은 문제라도 방법에 따라 걸리는 시간이 달라서, 효율적인 알고리즘을 고르는 것이 중요하다.
  • 정렬은 데이터를 기준에 따라 순서대로 늘어놓는 것이다. 작은 값부터 늘어놓으면 오름차순, 큰 값부터 늘어놓으면 내림차순이다.
  • 탐색은 여러 데이터 중에서 원하는 데이터를 찾는 것이다.
  • 4장의 sort()와 11장의 sort_values()는 한 줄로 정렬해 주었다. 이 장에서는 그 안에서 일어나는 일을 직접 코드로 만들고, 방법에 따라 교환 횟수와 탐색 횟수가 어떻게 다른지 비교한다.

두 값 바꾸기

두 값 바꾸기
temp = a      # 임시 변수에 옮겨 두기
a = b
b = temp

a, b = b, a                 # 한 줄로 바꾸기
x[i], x[j] = x[j], x[i]     # 리스트 항목 바꾸기
  • 정렬은 두 값의 자리를 바꾸는 일을 되풀이한다. 그래서 먼저 두 변수의 값을 맞바꾸는 방법을 알아 둔다.
  • a = b를 먼저 하면 a에 있던 값이 사라진다. 그래서 a의 값을 다른 변수(임시 변수)에 잠시 옮겨 둔다.
  • 파이썬은 a, b = b, a처럼 한 줄로 두 값을 맞바꿀 수 있다. 오른쪽의 값을 먼저 모두 읽은 뒤 왼쪽에 차례로 넣는다.
  • 리스트의 두 항목도 a[i], a[j] = a[j], a[i]로 맞바꾼다.

12.2버블 정렬

버블 정렬
for i in range(n - 1):              # 단계
    for j in range(n - 1 - i):      # 이웃한 두 값 비교
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
  • 버블 정렬(bubble sort)은 이웃한 두 값을 비교해 앞의 값이 더 크면 자리를 바꾸는 방법이다.
  • 앞에서부터 끝까지 한 번 비교하면(한 단계) 가장 큰 값이 맨 뒤로 밀려나 자리가 정해진다. 큰 값이 거품처럼 위로 떠오르는 모습이라 버블 정렬이라고 한다.
  • 값이 n개이면 n - 1단계를 거친다. 단계마다 맨 뒤의 정해진 값은 다시 비교하지 않으므로 비교 횟수가 하나씩 줄어든다.

12.3선택 정렬

선택 정렬
for i in range(n - 1):              # 기준 위치
    min_index = i
    for j in range(i + 1, n):       # 기준 뒤의 값들
        if a[j] < a[min_index]:
            min_index = j
    if min_index != i:
        a[i], a[min_index] = a[min_index], a[i]
  • 선택 정렬(selection sort)은 기준 위치를 정하고, 그 뒤의 값 중에서 가장 작은 값을 골라(선택해) 기준 위치의 값과 바꾸는 방법이다.
  • 0번 위치부터 기준으로 삼아 한 칸씩 뒤로 옮긴다. 단계마다 가장 작은 값이 앞에서부터 자리를 잡는다.
  • 가장 작은 값의 위치를 min_index에 기억해 두었다가 단계가 끝날 때 한 번만 바꾼다. 그래서 버블 정렬보다 교환 횟수가 적다.

파이썬 실습 12-8두 정렬의 교환 횟수 비교하기

7장의 함수와 return을 써서 같은 데이터를 두 방법으로 정렬한다.

def bubble(a):
    n = len(a)
    count = 0
    for i in range(n - 1):
        for j in range(n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                count += 1
    return count

def selection(a):
    n = len(a)
    count = 0
    for i in range(n - 1):
        min_index = i
        for j in range(i + 1, n):
            if a[j] < a[min_index]:
                min_index = j
        if min_index != i:
            a[i], a[min_index] = a[min_index], a[i]
            count += 1
    return count

print(bubble([9, 7, 5, 3, 1]), selection([9, 7, 5, 3, 1]))
print(bubble([1, 2, 3, 5, 4]), selection([1, 2, 3, 5, 4]))
10 2
1 1

해설두 정렬을 함수로 만들어 교환 횟수를 반환하게 했다. 거꾸로 늘어선 데이터에서 버블 정렬은 모든 쌍을 바꾸어 10번 교환하지만, 선택 정렬은 2번만 교환한다. 거의 정렬된 데이터에서는 둘 다 1번이다. 두 정렬 모두 비교는 4 + 3 + 2 + 1 = 10번으로 같다.

기억하기

  • 선택 정렬은 기준 위치 뒤에서 가장 작은 값의 위치(min_index)를 찾아 기준 위치의 값과 바꾼다.
  • 단계마다 교환은 많아야 한 번이다. 그래서 버블 정렬보다 교환 횟수가 적거나 같다.
  • 값이 n개이면 두 정렬 모두 n - 1단계이고, 비교 횟수는 같다.

def binary(a, target):
    left, right = 0, len(a) - 1
    while left <= right:
        mid = (left + right) // 2
        if a[mid] == target:
            return mid
        elif a[mid] > target:
            right = mid - 1   # 왼쪽 절반
        else:
            left = mid + 1    # 오른쪽 절반
    return -1
  • 이진 탐색(binary search)은 정렬된 데이터의 가운데 값과 비교해, 찾는 값이 왼쪽 절반에 있는지 오른쪽 절반에 있는지 판단하며 범위를 줄여 가는 방법이다.
  • 탐색 범위의 왼쪽 끝을 left, 오른쪽 끝을 right, 가운데를 mid = (left + right) // 2로 정한다. // 는 소수점 아래를 버리는 나눗셈이다.
  • 가운데 값이 찾는 값이면 끝낸다. 찾는 값이 더 작으면 right = mid - 1, 더 크면 left = mid + 1로 범위를 반으로 줄인다.
  • left가 right보다 커지면 더 찾을 곳이 없으므로 -1을 돌려준다.
  • 반드시 정렬된 데이터에서만 쓸 수 있다. 정렬되어 있어야 가운데 값과 비교해 한쪽 절반을 버릴 수 있다.

문제 4. 순차 탐색 함수 만들기

문제 5. 이진 탐색 함수 완성하기

정답

def binary(a, target):
    left, right = 0, len(a) - 1
    while left <= right:
        mid = (left + right) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            left = mid + 1
        else:
            right = mid - 1
    return -1

book = [101, 115, 128, 136, 142, 157, 163, 179]
print(binary(book, 157))
print(binary(book, 120))
5
-1

빈칸 답 : ㉠ len(a) - 1, ㉡ mid + 1, ㉢ mid - 1

풀이

문제 이해하기

가운데 값과 비교해 찾는 값이 있을 수 있는 쪽만 남긴다. 비교 방향이 바뀌면 left와 right의 자리도 바뀐다.

사용하는 개념

  • left와 right는 탐색 범위의 양 끝 위치이다.
  • 가운데 값이 작으면 오른쪽 절반(left = mid + 1), 크면 왼쪽 절반(right = mid - 1)을 남긴다.
  • left > right가 되면 -1을 돌려준다.

한 단계씩 따라가기

코드결과와 풀이
157 찾기mid 3(136 < 157) → left 4, mid 5(157) → 5
120 찾기mid 3(136) → right 2, mid 1(115) → left 2, mid 2(128) → right 1 → -1

자주 하는 실수

mid ± 1을 빼먹고 left = mid처럼 쓰면 범위가 한 칸 남았을 때 줄어들지 않아 반복이 끝나지 않을 수 있다.

문제 7. 이진 탐색의 비교 횟수 예측하기

정답

count = 0

def binary(a, target):
    global count
    count = 0
    left, right = 0, len(a) - 1
    while left <= right:
        count += 1
        mid = (left + right) // 2
        if a[mid] == target:
            return mid
        elif a[mid] > target:
            right = mid - 1
        else:
            left = mid + 1
    return -1

a = list(range(10, 160, 10))
print(len(a))
print(binary(a, 80), count)
print(binary(a, 150), count)

7 1
14 4

  • list(range(10, 160, 10))은 10부터 150까지 10씩 커지는 리스트이다.

문제 이해하기

  • 리스트의 마지막 위치는 len(a) - 1이다.
  • 연산자 우선순위 때문에 괄호가 필요하다.

코드결과와 풀이

자주 하는 실수

8처럼 있는 값만 시험하면 두 번째 오류가 보이지 않는다. 없는 값과 맨 끝의 값도 함께 시험해 본다.
