파일 알아보기
  • 변수에 저장한 값은 프로그램이 끝나면 사라진다. 파일에 저장하면 프로그램을 다시 실행해도 그 값을 읽어 쓸 수 있다.
  • 파일은 열기 → 쓰거나 읽기 → 닫기 순서로 다룬다.
  • 표 형태의 데이터는 쉼표로 값을 구분한 CSV 파일로 저장하고, 읽으면 2차원 리스트가 된다.

이 장의 텍스트 파일은 encoding='utf-8'로 저장하고 읽는다. 한글이 깨지지 않도록 쓸 때와 읽을 때 같은 문자 인코딩을 쓴다.

10.1

파일에 쓰기

파일에 쓰기
f = open('파일이름', '모드', encoding='utf-8')
f.write('문자열')
f.close()
  • open()은 파일을 열고, 그 파일을 다루는 파일 객체를 돌려준다. 이 파일 객체를 변수 f에 저장한다.
  • write()는 괄호 안의 문자열을 파일에 적는다. print()와 달리 줄을 바꾸어 주지 않으므로 줄 바꿈 문자 \n을 직접 넣는다.
  • write()에는 문자열만 넣을 수 있다. 숫자는 str()이나 f-문자열로 바꾸어 쓴다.
  • 다 쓴 파일은 close()로 닫는다. 닫아야 쓴 내용이 파일에 모두 저장된다.

코랩에서 파일 다루기
  • 코랩의 파일은 코랩 서버의 작업 폴더(content)에 저장된다. 왼쪽의 파일 창에서 확인하고, 파일 이름 옆의 메뉴로 내려받거나 지울 수 있다.
  • 세션이 끝나거나 런타임을 해제하면 작업 폴더의 파일도 사라진다. 남겨야 할 파일은 내려받아 둔다.

기억하기

  • 파일은 open()으로 열고, write()로 쓰고, close()로 닫는다.
  • 'w'는 새로 쓰기(기존 내용을 지움), 'a'는 이어 쓰기, 'r'은 읽기이다.
  • write()는 줄을 바꾸어 주지 않으므로 \n을 직접 넣는다.
  • write()에는 문자열만 넣는다. 숫자는 str()이나 f-문자열로 바꾼다.

10.2파일 읽기

파일 읽기
f = open('파일이름', 'r', encoding='utf-8')
a = f.read()          # 전체를 문자열 하나로
b = f.readlines()     # 줄마다 나눈 리스트로
for 줄 in f:          # 한 줄씩 꺼내 반복
    print(줄)
f.close()
  • 파일을 읽으려면 'r' 모드로 연다. 읽을 파일이 없으면 FileNotFoundError가 난다.
  • read()는 파일 전체를 문자열 하나로 읽는다.
  • readlines()는 파일을 한 줄씩 나누어 리스트로 돌려준다.
  • for 줄 in f:로 쓰면 파일에서 한 줄씩 꺼내 반복한다.
  • 읽은 줄의 끝에는 줄 바꿈 문자 \n이 붙어 있다. 그리고 읽은 값은 숫자처럼 보여도 문자열이다.

with로 파일 열기
with open('파일이름', '모드', encoding='utf-8') as f:
    파일을 다루는 코드
  • with 문으로 파일을 열면 들여쓴 코드가 끝날 때 파일이 자동으로 닫힌다. close()를 쓰지 않아도 된다.
  • 들여쓴 부분에서 오류가 나도 파일이 닫힌다.
  • with 줄 끝에는 콜론을 붙이고, 파일을 다루는 코드는 들여쓴다. 조건문·반복문·함수와 같은 규칙이다.

파이썬 실습 10-10with로 열고 자동으로 닫기

with open('fruit.txt', 'r', encoding='utf-8') as f:
    a = f.readlines()
print(a)
print(f.closed)
['사과\n', '포도\n', '귤\n']
True

해설as 뒤의 f가 연 파일을 가리킨다. 들여쓰기가 끝나는 곳에서 파일이 닫히므로 f.closed가 True(닫힘)이다. 읽어 둔 리스트 a는 그대로 쓸 수 있다.

기억하기

  • 읽을 파일은 'r'로 연다. 파일이 없으면 FileNotFoundError가 난다.
  • read()는 전체를 문자열 하나로, readlines()는 줄마다 나눈 리스트로 읽는다. for 줄 in f:로 한 줄씩 꺼낼 수도 있다.
  • 읽은 줄의 끝에는 \n이 있다. 그대로 출력하려면 print(줄, end='')를 쓴다.
  • 파일에서 읽은 값은 문자열이다. 계산하려면 int()나 float()로 바꾼다.
  • with로 열면 들여쓴 코드가 끝날 때 파일이 자동으로 닫힌다.

import csv

f = open('club.csv', 'w', encoding='utf-8', newline='')
csv.writer(f).writerows([['이름', '동아리'], ['다인', '코딩'], ['성민', '축구']])
f.close()

f = open('club.csv', 'r', encoding='utf-8')
rows = list(csv.reader(f))
f.close()
print(len(rows))
print(rows[1][1] + '부')
print(rows[2][0] * 2)
print(rows[0])
3
코딩부
성민성민
['이름', '동아리']

빈칸 답 : ㉠ 3, ㉡ 코딩부, ㉢ 성민성민, ㉣ ['이름', '동아리']

풀이

문제 이해하기

읽은 2차원 리스트를 먼저 적어 보고, 대괄호를 행 → 열 순서로 읽는다.

사용하는 개념

  • csv.reader로 읽은 한 행은 문자열 리스트이다.
  • 문자열은 +로 이어 붙이고, *로 반복한다.

한 단계씩 따라가기

코드결과와 풀이
len(rows)행 3개 → 3
rows[1][1] + '부''코딩' + '부' → 코딩부
rows[2][0] * 2'성민' * 2 → 성민성민
rows[0]['이름', '동아리']

자주 하는 실수

rows[1][1]을 1행이 아니라 첫 행(열 이름 행)으로 생각하기 쉽다. 인덱스는 0부터 세므로 rows[1]은 다인의 행이다.

문제 8. 파일 모드와 write() 오류 고치기

정답

f = open('price.txt', 'w', encoding='utf-8')
f.write(str(1500))
f.close()

f = open('price.txt', 'r', encoding='utf-8')
print(f.read())
f.close()
1500

빈칸 답 : ㉠ 'w', ㉡ str(1500)

풀이

문제 이해하기

오류를 하나 고치면 다음 오류가 보인다. 첫 번째 오류는 모드, 두 번째 오류는 write()에 넣은 값의 자료형이다.

사용하는 개념

  • 'r'은 있는 파일을 읽을 때만 쓴다. 새 파일에 쓰려면 'w'로 연다.
  • write()에는 문자열만 넣는다.

한 단계씩 따라가기

코드결과와 풀이
open('price.txt', 'r', ...)파일이 없어 FileNotFoundError가 난다.
open('price.txt', 'w', ...)파일을 새로 만든다.
f.write(1500)TypeError: write() argument must be str, not int
f.write(str(1500))문자열 '1500'을 써서 1500이 출력된다.

자주 하는 실수

f.write('1500')처럼 처음부터 따옴표로 묶어도 된다. 변수에 든 숫자를 쓸 때는 str()이나 f-문자열을 쓴다.
