8장 모듈

모듈 알아보기
  • 모듈은 재사용할 파이썬 코드를 모아 둔 파일이다.
  • 앞에서 배운 함수들을 .py 파일에 모아 모듈을 만든다.
  • import로 모듈을 불러오면 그 안의 함수를 가져다 쓸 수 있다.
  • 불러오는 방법이 여러 가지이고, 방법에 따라 호출하는 모양이 달라진다.
  • 함수에 독스트링을 적어 두면 help()로 사용법을 확인할 수 있다.
8.1

모듈 알아보기

import로 모듈 불러오기
import 모듈이름

모듈이름.함수이름(인수)
  • 모듈은 재사용할 파이썬 코드를 모아 둔 파일이다.
  • 모듈을 사용하려면 import로 불러온다.
  • 파이썬이 기본으로 제공하는 모듈도 있고, 내가 만들어서 쓰는 모듈도 있다.
  • 불러온 모듈의 함수는 모듈이름.함수이름() 형태로 호출한다.

파이썬 실습 8-1무작위 값을 다루는 모듈 사용하기

1부터 6까지의 수 중 하나를 무작위로 출력합니다. 실행할 때마다 결과가 달라집니다.

import random

print(random.randint(1, 6))
실행 예시
3

해설random은 무작위 값을 다루는 모듈이다. randint(1, 6)은 1과 6을 포함한 정수 하나를 고른다.

파이썬 실습 8-2시간을 다루는 모듈 사용하기

import time

for i in range(3, 0, -1):
    print(i)
    time.sleep(1)
print('출발!')

2
1
출발!

해설time.sleep(1)은 약 1초 동안 기다린다. 3, 2, 1을 차례로 출력한 뒤 출발 메시지를 출력한다.

파이썬이 기본으로 제공하는 모듈

모듈하는 일예
random무작위 값 만들기random.randint(1, 6)

기억하기

  • 모듈에는 변수·함수·클래스 등 파이썬 코드를 담을 수 있다.
  • import 모듈이름으로 불러온 뒤 모듈이름.함수이름()으로 호출한다.
  • random, time처럼 파이썬이 기본으로 주는 모듈이 있다.

8.2모듈 파일 만들기

모듈 파일 만들기
  • 함수들을 .py 파일 하나에 모아 모듈로 만든다.
  • 확장자 .py를 뺀 파일 이름이 모듈 이름이 된다.
  • 코랩에서는 왼쪽 파일 창에서 새 파일을 만들 수 있다.
  • 이 실습에서는 함수 정의를 모듈에 넣고, 함수 호출은 별도 코드 셀에서 한다.

코랩 화면왼쪽의 파일 아이콘을 누르고 빈 곳에서 마우스 오른쪽 버튼을 눌러 새 파일을 만든다. 이어서 파일 이름을 my_func.py로 입력한다.

코랩 화면만든 파일을 더블클릭하면 오른쪽에 편집 창이 열린다. 여기에 함수 코드를 붙여 넣는다.

파이썬 실습 8-3my_func.py에 넣을 함수 작성하기

아래 코드를 복사해 my_func.py에 붙여 넣고 저장합니다.

def last4(x):
    """문자열 x의 마지막 4글자를 출력하는 함수"""
    print(x[-4:])

def plus_print(x):
    """'+'로 연결된 문자열을 계산해 출력하는 함수"""
    a, b = x.split('+')
    print(int(a) + int(b))

def plus_return(x):
    """'+'로 연결된 문자열을 계산해 반환하는 함수"""
    a, b = x.split('+')
    return int(a) + int(b)

def small(x):
    """문자열 x를 모두 소문자로 바꾸어 반환하는 함수"""
    return x.lower()

def sum1(x):
    """1부터 x까지의 합을 구해 출력하는 함수"""
    s = 0
    for i in range(1, x + 1):
        s = s + i
    print(f'1부터 {x}까지의 합은 {s}입니다.')

def list_sum(x):
    """리스트 x 안에 있는 숫자들의 합을 출력하는 함수"""
    s = 0
    for i in range(len(x)):
        s = s + x[i]
    print(s)

def double(x):
    """리스트 x의 숫자를 각각 2배로 만들어 출력하는 함수"""
    b = []
    for i in x:
        b.append(i * 2)
    print(b)

해설문자열과 리스트를 다루는 함수를 한 파일에 모았다. 파일을 저장하면 my_func 모듈로 불러올 수 있다.

이 실습의 모듈 파일 작성 규칙

항목내용
파일 이름my_func.py처럼 영문자와 밑줄을 사용하고 공백은 넣지 않는다
파일 안의 내용이 실습에서는 함수 정의를 모아 둔다
호출하는 위치my_func.last4(...) 같은 호출은 별도 코드 셀에 쓴다
이름이 겹치지 않게 하기파일 이름은 random.py, time.py 등 기본 모듈 이름과 겹치지 않게 짓는다

기억하기

  • .py 파일 하나가 모듈 하나가 된다.
  • 파일 이름이 모듈 이름이므로 확장자를 뺀 이름으로 불러온다.
  • 이 실습의 모듈에는 함수 정의를 넣고, 호출은 별도 코드 셀에서 한다.

8.3import로 모듈 불러오기

같은 폴더에 있는 모듈 불러오기
import 파일명

파일명.함수명(인수)
  • 모듈 파일이 지금 작업하는 곳과 같은 위치에 있으면 import 파일명으로 불러온다.
  • 확장자 .py는 쓰지 않는다.
  • 불러온 뒤에는 파일명.함수명(인수)으로 호출한다.
  • 반환값이 있는 함수는 변수에 받거나 print() 안에 넣어 사용한다.

파이썬 실습 8-4모듈을 불러와 함수 호출하기

import my_func

my_func.last4('01033857220')
7220

해설import my_func로 불러온 뒤 my_func.last4()로 호출한다. 마지막 4글자인 7220이 출력된다.

파이썬 실습 8-5반환값을 바로 출력하기

import my_func

print(my_func.plus_return('12+34'))
46

해설plus_return()이 반환한 46을 print()로 바로 출력한다.

파이썬 실습 8-6반환값을 변수에 받아 사용하기

import my_func

a = my_func.plus_return('12+34')
print(a)
print(a + 4)
46
50

해설반환값 46을 변수 a에 저장한다. 같은 값을 다시 사용해 50도 출력한다.

반환값을 사용하는 방법

모듈의 함수반환값호출하는 방법
last4()Nonemy_func.last4(값)
plus_print()Nonemy_func.plus_print(값)
plus_return()계산하거나 변환한 값a = my_func.plus_return(값)
small()계산하거나 변환한 값b = my_func.small(값)

기억하기

  • 같은 위치에 있는 모듈은 import 파일명으로 불러온다.
  • 확장자 .py는 쓰지 않는다.
  • 호출할 때는 파일명.함수명()처럼 앞에 모듈 이름을 붙인다.
  • 반환값이 있는 함수는 변수에 받아서 사용한다.

8.4폴더에 모아 불러오기

폴더 안에 있는 모듈 불러오기
from 폴더명 import 파일명

import 폴더명.파일명
  • 모듈 파일이 많아지면 폴더에 모아 정리한다.
  • 폴더 안의 모듈은 폴더 이름까지 함께 적어야 찾을 수 있다.
  • from 폴더명 import 파일명을 쓰면 호출할 때는 파일명만 쓴다.
  • import 폴더명.파일명을 쓰면 호출할 때도 폴더명부터 모두 쓴다.

코랩 화면파일 창의 빈 곳에서 마우스 오른쪽 버튼을 눌러 새 폴더를 만들고 이름을 module로 입력한다.

코랩 화면만들어 둔 my_func.py를 module 폴더 위로 끌어다 놓아 옮긴다.

파이썬 실습 8-7from으로 폴더 안의 모듈 불러오기

from module import my_func

b = my_func.small('aPplE')
print(b)
apple

해설from 뒤에는 폴더 이름을 쓴다. 호출할 때는 my_func.small()처럼 모듈 이름부터 쓴다.

파이썬 실습 8-8import만 써서 폴더 안의 모듈 불러오기

import module.my_func

module.my_func.sum1(10)
1부터 10까지의 합은 55입니다.

해설import module.my_func로 불러오면 호출할 때도 폴더 이름부터 모두 쓴다.

같은 모듈을 불러오는 두 가지 방법

불러오기호출하기
from module import my_funcmy_func.sum1(10)
import module.my_funcmodule.my_func.sum1(10)

기억하기

  • 폴더 안의 모듈은 폴더 이름까지 알려 주어야 찾을 수 있다.
  • from 폴더명 import 파일명으로 불러오면 파일명.함수명()으로 호출한다.
  • import 폴더명.파일명으로 불러오면 폴더명.파일명.함수명()으로 호출한다.
  • 불러오는 방법에 따라 호출하는 방법도 달라진다.

8.5별명 붙이기와 함수만 가져오기

별명 붙이기와 함수만 가져오기
import 폴더명.파일명 as 별명

from 폴더명.파일명 import 함수명
  • as를 쓰면 모듈에 짧은 별명을 붙일 수 있다.
  • from 폴더명.파일명 import 함수명을 쓰면 함수만 가져온다.
  • 함수만 가져오면 모듈 이름 없이 함수 이름만으로 호출한다.
  • 쉼표로 구분하면 필요한 함수를 여러 개 가져올 수 있다.

파이썬 실습 8-9모듈에 별명 붙이기

import module.my_func as mf

mf.list_sum([10, 20, 30])
60

해설as mf로 별명을 붙였으므로 mf.list_sum()으로 호출한다.

파이썬 실습 8-10함수만 가져와서 호출하기

from module.my_func import double

double([10, 20, 30])
[20, 40, 60]

해설double만 가져왔으므로 모듈 이름 없이 double()로 호출한다.

파이썬 실습 8-11여러 함수를 한 번에 가져오기

from module.my_func import last4, plus_print

last4('01033857220')
plus_print('100+200')
7220
300

해설쉼표로 구분해 두 함수를 가져온다. import *보다 필요한 이름을 직접 적으면 코드의 뜻이 분명해진다.

모듈을 불러오는 다섯 가지 방법

불러오기호출하기쓰는 경우
import my_funcmy_func.small(값)같은 위치에 있을 때
from module import my_funcmy_func.small(값)폴더 안에 있을 때
import module.my_funcmodule.my_func.small(값)위치를 분명히 밝힐 때
import module.my_func as mfmf.small(값)이름이 길 때
from module.my_func import smallsmall(값)함수 한두 개만 쓸 때

기억하기

  • as로 모듈에 별명을 붙일 수 있다.
  • from 모듈 import 함수명으로 함수만 가져오면 모듈 이름 없이 호출한다.
  • 불러오는 방법이 달라지면 호출하는 방법도 함께 달라진다.

8.6독스트링과 help

독스트링과 help
def 함수이름(매개변수):
    """함수를 설명하는 글"""
    실행할 코드
  • 함수나 모듈 본문의 맨 처음에 쓰는 문자열을 독스트링이라고 한다.
  • 독스트링은 보통 큰따옴표 세 개로 묶어 적는다. 여러 줄로 쓸 수도 있다.
  • help()로 그 설명을 꺼내 볼 수 있다.
  • 내가 만든 모듈도 독스트링을 적어 두면 help()에 나온다.

8.4에서 옮긴 module/my_func.py를 그대로 사용합니다.

상황독스트링이 하는 일
내가 만든 모듈을 남에게 줄 때받은 사람이 help()로 사용법을 확인한다
한참 뒤에 내 코드를 다시 볼 때무엇을 하는 함수였는지 바로 알 수 있다
함수 이름만으로 뜻이 불분명할 때매개변수와 반환값을 글로 남겨 둔다

기억하기

  • 독스트링은 함수나 모듈 본문의 맨 처음에 적는 설명 문자열이다.
  • help(함수이름)으로 설명을 본다. 전달할 함수 이름 뒤에는 ()를 붙이지 않는다.
  • help(모듈이름)을 쓰면 모듈 안의 함수 목록이 나온다.
  • 모듈은 남이 쓰는 경우가 많으므로 독스트링을 적어 둔다.

문제 2. 반환값을 변수에 받아 사용하기

문제 6. 모듈의 설명 확인하기

정답

import my_func

help(my_func.small)
Help on function small in module my_func:

small(x)
    문자열 x를 모두 소문자로 바꾸어 반환하는 함수

풀이

문제 이해하기

help()에 함수 이름을 넣으면 독스트링이 나온다.

사용하는 개념

  • 함수 본문의 맨 처음에 설명 문자열을 적으면 독스트링이 된다.
  • help()는 그 설명을 꺼내 보여 준다.

한 단계씩 따라가기

코드결과와 풀이
help(my_func.small)small 함수에 적어 둔 설명이 출력된다.
전달할 함수 이름 뒤에 ()를 붙이지 않는다help(my_func.small())처럼 쓰면 함수가 실행된다.

자주 하는 실수

함수를 실행하라는 것이 아니라 설명을 보여 달라는 것이므로 help(my_func.small)처럼 이름만 넣는다.
