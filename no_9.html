9장 클래스

클래스 알아보기
  • 클래스는 관련 있는 변수와 함수를 하나로 묶어 놓은 설계도이다. 7장에서 명령을 함수로 묶었다면, 클래스는 함수와 변수를 함께 묶는다.
  • 클래스로 만든 실제 값을 객체라고 한다. 하나의 클래스로 객체를 여러 개 만들 수 있다.
  • 객체가 가진 변수를 속성, 클래스 안에 정의한 함수를 메서드라고 한다.
  • 객체마다 속성을 따로 가지므로, 같은 메서드를 써도 객체마다 다른 값을 다룬다. 예를 들어 같은 계좌 클래스로 만든 두 사람의 계좌는 용돈이 섞이지 않는다.
  • 4장의 리스트도 list 클래스로 만든 객체이다. a.append(4)처럼 객체 뒤에 점을 찍고 메서드를 호출했던 것이다.

9.3메서드와 self

self 알아보기
class 클래스이름:
    def 메서드이름(self, 매개변수):
        self.속성이름 = 값
  • 이 장에서 객체로 호출하는 메서드는 첫 번째 매개변수에 self를 쓴다.
  • self에는 그 메서드를 호출한 객체가 자동으로 들어간다. 객체이름.메서드이름()에서 점 앞에 있는 것이 self가 된다.
  • 객체마다 따로 가질 값에는 이름 앞에 self.를 붙인다.
  • self.total = money처럼 대입하면 그 객체의 속성에 값이 저장된다.

파이썬 실습 9-7객체마다 잔액을 따로 저장하기

    def set_money(self, money):
        self.total = money

    def show(self):
        print(f'[잔액] {self.total}원')

lee = Account()
kim.set_money(10000)
lee.set_money(5000)
kim.show()
lee.show()
[잔액] 10000원
[잔액] 5000원

해설kim.set_money(10000)의 self는 kim, lee.set_money(5000)의 self는 lee이다. 잔액이 각 객체의 total 속성에 따로 저장되므로 9.1과 달리 사람마다 함수를 새로 만들 필요가 없다.

global과 self 비교하기

방법값을 어디에 두나사람이 늘어나면
global total전역 변수 total 하나변수와 함수를 사람마다 추가한다
self.total객체마다 하나씩객체만 하나 더 만들면 된다

기억하기

  • self는 그 메서드를 호출한 객체이다. 점 앞에 있는 객체가 self로 자동 전달된다.
  • 객체마다 따로 가질 값에는 self.를 붙인다. self.를 빠뜨리면 지역 변수가 된다.
  • self는 예약어가 아니지만, 관례에 따라 이 이름을 쓴다.

9.4__init__으로 초깃값 정하기

__init__ 알아보기
class 클래스이름:
    def __init__(self, 매개변수):
        self.속성이름 = 매개변수
  • __init__은 객체를 만들 때 자동으로 호출되어 초깃값을 정하는 메서드이다.
  • 밑줄은 앞에 두 개, 뒤에 두 개를 붙인다.
  • 객체를 만들 때 괄호에 넣은 값이 __init__의 매개변수로 전달된다.
  • 7장에서 배운 매개변수 기본값을 쓰면 값을 넣지 않고도 객체를 만들 수 있다.
